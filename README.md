# 圓面積推導互動教具

不依賴外部套件、無廣告，適合 iPad、手機與電腦。學生可操作完整圓、等分扇形、展開、收合、集中排列、群組移動，並透過兩題挑戰推導 `圓面積 = πr²`。

## 部署到 GitHub Pages

1. 在 GitHub 建立新的 repository，例如 `circle-area-lab`。
2. 將本資料夾內的 `index.html`、`style.css`、`app.js` 上傳到 repository 根目錄。
3. 開啟 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. Branch 選 `main`，資料夾選 `/ (root)`，按 **Save**。
6. 等待約 1–3 分鐘，網址通常是 `https://你的帳號.github.io/circle-area-lab/`。

若要覆蓋舊版本，直接上傳這三個同名檔案並 Commit changes，不必刪除 repository 或重新設定 Pages。

## 教學流程

完整圓 → 等分扇形 → 展開 → 上下交錯集中排列 → 找出底與高 → 推導 πr²。

等分數可選 8–200 份，建議依序比較 8、48、200 份。
